# GpOne

## Regole di lavoro
- Non eseguire compilazioni (`dotnet build`, `msbuild`, `dotnet run`) né test (`dotnet test`)
  se non viene chiesto esplicitamente: compilazione e prove le fa l'utente in Visual Studio.
- Risparmia i token il più possibile: leggi solo le parti di file necessarie, niente esplorazioni
  o verifiche superflue, modifiche mirate, risposte e riepiloghi brevi.
